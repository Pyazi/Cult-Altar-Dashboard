# Контекст проекта: Алтарь Управления (Cult Altar Dashboard)

## 1. Суть проекта и архитектура
Это настольный виджет-монитор и пульт управления ПК (Windows, в перспективе Linux / Steam Deck), который превращает старые смартфоны, планшеты и современные устройства в дополнительный сенсорный экран по локальной сети Wi-Fi.
- **Стек:** Python 3, `PyQt6` (десктопный конструктор холста), `psutil` (телеметрия), `websockets` (порт `8081`), встроенный `ThreadingHTTPServer` (порт `8080`), `winrt` (перехват уведомлений Windows без чтения текста), `qrcode` (генерация QR в памяти).
- **Файлы:** `PC_Editor.py` (сервер + GUI редактор), `index.html` (веб-клиент для телефона), `cult_altar.ico`, `cult_config.json`, `cult_preset.json`, папка `cult_media/`.
- **Целевые устройства:**
  - Старые смартфоны на **Android 4, 5, 6 (1 ГБ ОЗУ)** и **iOS 12** (главный приоритет по производительности и совместимости).
  - Современные смартфоны (CMF Phone 2 Pro и др.) и **Steam Deck (SteamOS / Linux)**.

## 2. Строгие правила разработки (НЕ НАРУШАТЬ)
1. **Никакой переписки файлов с нуля:** База `v1.0.0` уже отлично работает (верстка, кнопка полноэкранного режима, оригинальные SVG-иконки Telegram/Discord/Steam, логика привязки виджетов). Вносить только **точечные изменения (diff)** под конкретную задачу.
2. **Совместимость со старым WebView / Chrome (Android 4–6):**
   - В `index.html` использовать только совместимый **ES5 JavaScript** (без `.padStart()`, `URLSearchParams`, стрелочных функций и современных методов, ломающих старый движок).
   - В CSS **запрещены** `inset: 0` (использовать `top: 0; left: 0; right: 0; bottom: 0`), `backdrop-filter: blur` и тяжелые фоновые текстуры.
   - Смена тем на мобильном клиенте должна работать исключительно через легкие **CSS-переменные**, без перестройки DOM-дерева и утечек памяти.
3. **Защита от утечек ОЗУ в PyQt6:** При выгрузке окна или смене пресета обязательно останавливать и удалять `QMovie` (GIF-анимации) через `stop()` и `deleteLater()`.
4. **Сборка:** Приложение должно корректно собираться в один исполняемый файл через `PyInstaller --onefile --noconsole`. Все внешние конфиги (`languages.json`, `cult_config.json`, `cult_preset.json`) при отсутствии рядом с `.exe` должны автоматически создаваться из встроенного словаря по умолчанию.

## 3. План развития (Roadmap v2.0 — делать строго по 1 пункту за раз)

### Этап 1: Быстрое подключение (IP + QR-код)
- Выводить в шапке окна кликабельный локальный `IP:8080` (с умным определением основного Wi-Fi/Ethernet адаптера, игнорируя VPN/Radmin/виртуальные сети, плюс выбор IP в Настройках).
- Добавить кнопку **`📱 QR`**: открывает диалог с контрастным QR-кодом ссылки `http://IP:8080/?pin=XXXX` (для автовхода камерой современных смартфонов) и текстом `IP:порт` + `PIN` снизу (для ручного ввода на старых Android 4–6).

### Этап 2: Системный трей и экономия памяти (Windows)
- При нажатии на крестик `[X]` программа не закрывается, а сворачивается в системный трей (`QSystemTrayIcon`).
- **Оптимизация ОЗУ:** при сворачивании в трей окно конструктора полностью выгружается из памяти (`deleteLater()` + `gc.collect()`, все GIF останавливаются), в фоне работает только сервер и иконка трея (~35–45 МБ ОЗУ).
- Левый клик по иконке трея заново открывает редактор; правый клик показывает текущий `IP:порт | PIN`, «Открыть редактор» и «Закрыть полностью».

### Этап 3: Внешний файл локализации (`languages.json`)
- Вынести все тексты интерфейса ПК и веб-панели в `languages.json` (базовые языки: `ru` и `en`).
- В Настройках сделать динамический выбор языка из этого файла, чтобы пользователи на GitHub могли сами добавлять свои переводы. Смена языка должна обновлять и ПК, и телефон.

### Этап 4: Темы оформления (сохраняя стиль v1.0 по умолчанию)

### Этап 5: Улучшение холста редактора
- Добавить примагничивание (snap) не только при перетаскивании карточек, но и при **изменении их размера** (чтобы правый и нижний края выравнивались по границам соседних виджетов).

### Этап 6: Поддержка Linux и Steam Deck (SteamOS) — [ВЫПОЛНЕНО в v2 напрямую в PC_Editor.py]
- Единый кроссплатформенный код с разделением по `sys.platform == "win32"` и `sys.platform.startswith("linux")`.
- Медиа и громкость: сохранена Windows-реализация (WinAPI / ctypes), на Linux добавлено управление громкостью через `wpctl` (WirePlumber / Steam Deck), `pactl` (PulseAudio), `amixer` (ALSA), а также медиаплеер и чтение треков Spotify через `playerctl` и D-Bus MPRIS.
- Запуск приложений: безопасный запуск через `launch_application(path)` с поддержкой `os.startfile` на Windows и `xdg-open` / `subprocess.Popen` / `steam://` на Linux.
- Уведомления: на Windows используется `winrt`, на Linux — перехват `org.freedesktop.Notifications` через `dbus-monitor` без падений при отсутствии модулей.
- Автозапуск и Steam Deck: автозапуск на Linux через пользовательскую службу `~/.config/systemd/user/cult-altar.service`, поддержка запуска сервера `--headless` без GUI, встроенный бинарный парсер и сериализатор `shortcuts.vdf` и кнопка в Настройках «🎮 Добавить в игровой режим Steam».
